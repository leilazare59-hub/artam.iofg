# سایت نصب بازی

این پروژه برای نمایش و دانلود مستقیم فایل APK طراحی شده است.

## نحوه استفاده:
1. فایل بازی خود را با نام `app-release.apk` در پوشه `public` قرار دهید.
2. دستور `npm run build` را اجرا کنید.
3. محتویات پوشه `dist` را در GitHub Pages یا هر هاست دیگری آپلود کنید.

## ویژگی‌ها:
- کاملاً فارسی و راست‌چین (RTL)
- نصب‌شونده (PWA)
- طراحی مدرن و واکنش‌گرا
- حداقل تعداد فایل برای مدیریت آسان
